# Rack Shelf and Three-Node Installation

**Status:** Completed — October 2026  
**Category:** Physical Infrastructure / Rack Integration

## Overview

Installed VEVOR 1U vented cantilever shelves in the homelab rack and integrated three Proxmox micro-PC nodes with the custom 3D-printed three-tier holder.

## Completed Work

- [x] Identified the rack's **12-24 threaded round holes**
- [x] Resolved incompatibility with the screws included with the shelves
- [x] Selected compatible **12-24 mounting screws and washers**
- [x] Mounted the rack shelves
- [x] Printed and assembled the custom micro-PC holder
- [x] Installed the Dell OptiPlex 7020 Micro and two HP Elite Mini 600 G9 nodes
- [x] Completed holder cable management and physical checks

## Lessons Learned

Verify rack-hole thread specifications before selecting fasteners. Shelf hardware bundled for other rack types may not be compatible with 12-24 threaded rails. Washers help provide appropriate bearing area at the shelf mounting points.
